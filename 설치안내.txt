SHOOTDORI 경기기록시스템 안내 (Ver.0.10, 2026-10-15)

이 웹앱은 승률계산기 구글 시트를 "읽기만" 합니다.
시트 편집 권한이나 Apps Script는 필요 없고, 시트가 "링크가 있는 모든 사용자 - 보기" 상태면 됩니다.

[올릴 파일 — 모두 저장소 맨 위(같은 폴더)에]
  index.html               웹앱 본체
  manifest.webmanifest     홈 화면 앱 정보(이름·아이콘)
  apple-touch-icon.png     아이폰 홈 화면 아이콘
  icon-192.png             안드로이드 아이콘
  icon-512.png             안드로이드 아이콘(큰 크기)
  icon-maskable-512.png    안드로이드 원형·둥근 아이콘용

[팀원에게 공개하기 (GitHub Pages)]
  1. GitHub 저장소에 위 6개 파일을 업로드 (폴더 없이 맨 위에)
  2. Settings > Pages > Branch: main / (root) > Save
  3. 1~2분 뒤 나오는 주소를 단톡방에 공유

[홈 화면에 추가]
  - 아이폰(사파리): 공유 버튼 > "홈 화면에 추가" → 이름 "경기기록", SHOOTDORI 엠블럼 아이콘
  - 안드로이드(크롬): 오른쪽 위 ⋮ > "홈 화면에 추가" 또는 "앱 설치"
  - 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 열립니다.
  - 이미 예전 아이콘으로 추가해 둔 경우, 지우고 다시 추가해야 새 아이콘이 나옵니다.

[동작 방식]
  - 페이지를 열 때마다 시트의 Members, Games, Match_Player, Stats 탭을 그대로 읽어 옵니다.
  - 기록 담당자가 시트를 고치면, 팀원이 새로고침만 해도 바로 반영됩니다.
  - 시트를 읽지 못하면 10월 15일 저장본을 보여 주고, 상단에 "10월 15일 저장본"이라고 표시됩니다.
  - 각 팀원은 [개인 기록] 탭에서 "내 이름 저장"을 누르면 다음부터 자기 기록이 바로 열립니다. (기기별 저장)

[알아 둘 점]
  - 시트의 필터로 숨겨 둔 행도 모두 읽어 옵니다. (시트 정렬·필터 상태와 상관없이 전체 표시)
  - 각 탭은 주소창의 #gid= 번호로 찾아 읽습니다.
    탭을 지우고 다시 만들면 번호가 바뀌므로, 그때는 index.html의 CONFIG.SHEETS 번호를 새 번호로 고쳐 주세요.
    (번호가 맞지 않으면 탭 이름으로 다시 시도하지만, 이 경우 필터로 숨긴 행은 빠질 수 있습니다)
